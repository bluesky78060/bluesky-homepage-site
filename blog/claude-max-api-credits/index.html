Claude Max 구독자의 월 API 크레딧 받는 법

발행 2026.10.11
  • #Claude
  • #API
  • #크레딧

푸르공님의 유튜브 튜토리얼(Claude Max API 크레딧 받는 법 | 매달 최대 200달러, 3분 13초)에서 소개된 내용을 공식 문서와 대조해 정리했습니다. Anthropic 공식 영상이 아닙니다. https://youtu.be/BqrK7bqCTU4?si=O_qopPfCRLWb_Pik

얼마를 받나

Claude Max 5x 구독자는 매달 100달러, Max 20x 구독자는 200달러의 API 크레딧을 받습니다.

받는 방법

claude.ai 설정의 결제 메뉴에서 API 크레딧 항목을 열고 ’링크 organization’을 누른 뒤, 연결할 Claude Console 조직을 선택하면 됩니다. 카드 등록은 필요 없습니다.

한 가지 주의할 점이 있습니다. claude.ai와 Console에 같은 계정으로 로그인해야 크레딧 메뉴가 보입니다. 영상 속 제작자도 이 때문에 처음에는 메뉴를 찾지 못했다고 합니다.

어디에 쓸 수 있나

크레딧은 API, Playground, Agent SDK 등 API 쪽에서만 쓸 수 있습니다. 평소 쓰는 Claude 앱이나 대화형 Claude Code에는 적용되지 않습니다.

claude -p나 Agent SDK도 API 키를 직접 넣어 실행할 때만 크레딧을 씁니다. Claude 계정으로 로그인해서 실행하면 기존 구독 한도를 씁니다.

주의할 점

다음 달로 이월되지 않습니다. 결제 주기가 끝나면 사라집니다. 영상 화면 기준 만료일은 11월 1일이었습니다.

크레딧을 다 쓰면 요청이 멈출 뿐, 요금이 청구되지는 않습니다.

연결할 수 있는 조직은 하나이며, 바꾸려면 지원팀에 요청해야 합니다.

구독 후 7일이 지나야 크레딧을 받을 수 있습니다. 이 조건은 영상에 빠져 있습니다.

Max 구독자는 구독자 본인이, Console에서는 Owner, Admin 또는 Billing 역할이 있어야 연결할 수 있습니다.
