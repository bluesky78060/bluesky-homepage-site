Aside: 로그인된 웹에서 일을 끝내는 AI 브라우저

발행 2026.10.10
  • #Aside
  • #AI브라우저
  • #자동화

브라우저가 일을 끝까지 한다

Aside는 Chromium 엔진을 포크한 독립 브라우저로, 로그인된 실제 웹사이트와 로컬 파일 사이를 오가며 복잡한 일을 수행하도록 설계됐습니다. 요약을 만드는 데서 멈추지 않고, 여러 사이트와 파일을 넘나드는 실행이 제품의 중심입니다.

가장 다른 점은 기존 ChatGPT, Claude, GitHub Copilot 구독을 연결해서 쓸 수 있다는 것입니다. AI 요금을 새로 내는 대신 이미 결제 중인 구독을 OAuth로 재사용하거나 API 키를 직접 연결합니다.

만든 팀은 한국인 3인 창업팀 Aside Computer Inc.로, Y Combinator Fall 2025에 합류했습니다. 처음에는 AI 영업 어시스턴트로 시작했지만 고객 정보가 여러 도구에 흩어져 API 연동이 병목이 되자, 2026년 1월 브라우저로 전면 피벗했습니다. macOS 버전은 2026년 6월, Windows 버전은 9월에 출시됐습니다.

주요 기능

  • 자연어 다단계 작업: 사이트 탐색, 웹 검색, 파일 사용, 히스토리 검색을 이어서 수행합니다. 입력이나 승인이 필요하면 멈췄다가 다시 이어갈 수 있습니다.
  • 로그인된 환경에서 실행: 페이지 열기, 폼 작성, 파일 다운로드, 로컬 문서와 스프레드시트 작업이 가능합니다. 2단계 인증과 CAPTCHA는 사람이 처리하고, 결제와 발행은 승인 지점에서 멈춥니다.
  • 로컬 메모리: 방문 기록과 채팅, 작업 활동에서 컨텍스트를 재사용합니다. 저장 여부와 보존 기간을 직접 정할 수 있습니다.
  • 루틴: Cron 루틴은 일정에 새 작업을 시작하고, Heartbeat 루틴은 기존 채팅을 깨워 이어갑니다. 반복 패턴을 감지해 초안을 제안하기도 합니다.
  • 개발자 도구: 터미널에서 aside 명령으로 작업을 시작하고, aside mcp로 다른 에이전트나 코딩 도구에 연결합니다.
  • Vault: 비밀번호 원문을 AI 모델 컨텍스트에 노출하지 않고 자동입력을 처리합니다.
  • 권한 조절: Read only, Guard(기본값), Full access 세 단계로 작업 범위를 정합니다. Deny가 가장 우선합니다.

요금과 시작하기

2026년 10월 기준 공식 요금은 Free(월 500 크레딧, 루틴 3개), Pro(월 $20), Max(월 $200), Enterprise(문의)입니다. Free 플랜에도 기존 AI 구독 연결이 포함됩니다.

시작 순서는 간단합니다. Settings → Models → Providers에서 AI를 연결하고, Settings → Agents에서 권한을 정한 뒤(처음에는 기본값인 Guard 권장), 작업 페이지·사이드 패널·루틴 중 맞는 진입점을 고릅니다. 요청문은 “대상 → 범위 → 결과물 → 저장 위치 → 금지·승인 조건” 순서로 쓰면 에이전트가 해야 할 일과 멈춰야 할 지점이 분명해집니다.

한계와 주의할 점

강력한 만큼 주의할 점도 있습니다. 웹페이지나 이메일 속 지시가 AI를 조종하는 프롬프트 인젝션 위험이 있어, 계정에 직접 접근하는 만큼 최소 권한과 승인 검토가 중요합니다. 2FA와 CAPTCHA는 사람이 처리해야 하고, 결제·발행은 승인 게이트에서 멈춥니다.

숫자를 볼 때는 맥락을 함께 봐야 합니다. 공식 사이트가 내세우는 벤치마크 1위(Online-Mind2Web 99.0%)나 출시 2주 2만 사용자 같은 수치는 Aside 측 주장으로, 독립 검증된 공식 통계는 공개되지 않았습니다. 가격과 제품 상태도 계속 바뀌니 확인할 때는 공식 페이지를 직접 보는 편이 좋습니다.
