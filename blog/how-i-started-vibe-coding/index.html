바이브 코딩을 시작하게 된 경위

발행 2026.10.05

기록으로 본 시작

GitHub에 처음 남은 저장소는 2025년 9월 21일의 Postal-Code입니다. 엑셀에 담긴 주소 데이터로 우편번호를 찾아 A4 라벨로 인쇄하는 도구였고, 같은 날 안에 첫 구현과 라벨 인쇄 스타일, Windows 지원까지 커밋이 올라갔습니다. 2026년 10월 5일 기준으로 커밋이 248개 쌓였습니다.

  • 2025년 10월: Architecture-Management를 만들며 GitHub Pages 자동 배포와 Playwright E2E 테스트를 붙였습니다.
  • 2025년 11월: flutter-todo를 Supabase와 Vercel 배포까지 이어서 만들었습니다.
  • 2025년 12월: 업무에 쓰는 데스크톱 앱을 시작했습니다.
  • 2026년 2월: 필지 자료를 다루는 도구와 AI로 프로젝트를 관리하는 ai-pm-system을 만들었습니다.
  • 2026년 10월: 집게 0.10 베타를 내고, 이 사이트를 열었습니다.

시작한 이유

바이브 코딩을 알게 된 뒤로 궁금해서 이것저것 해 보기 시작했습니다. 처음 만든 것은 업무에 쓸 웹사이트였습니다. 우편번호를 검색하고 라벨지를 뽑을 수 있는 도구입니다.

그러고 나서 여러 개를 만들기 시작했습니다. DoDo 같은 일정 관리 앱, 지금 업무에 쓰고 있는 앱 같은 것들입니다.

토큰 소비가 너무 많아서 개발의 흐름이 끊긴다는 점입니다. 하고 싶은 것은 많은데 중간에 흐름이 끊기니, 그게 가장 큰 어려움입니다.

제가 구상하는 것을 만들 수 있겠다는 자신감이 생긴 것입니다. 시작하고 가장 크게 달라진 점입니다.
