집게

글을 고르면 그 아래에 작은 팝업 바를 띄우는 macOS 메뉴 막대 앱입니다. 한/영 오타 되돌리기, 조사 고치기 같은 한국어에 맞춘 동작과 온디바이스 AI를 쓰던 창에서 바로 씁니다.

설치 전 확인할 것

번역·다듬기·AI는 macOS 26 이상에서 쓸 수 있습니다.

집
주요 기능

집게에서 할 수 있는 일

  • 한/영 바꾸기

    자판을 잘못 두고 친 글을 되돌립니다.

    dkssudgktpdy → 안녕하세요

  • 조사 고치기

    틀린 조사를 고칩니다.

    책를 → 책을 · 서울으로 → 서울로

  • 스마트

    고른 글이 주소·수식·치수·색 코드이면 주소 열기, 수식 계산, 단위 환산, 색 코드 변환을 합니다.

  • 번역

    한국어는 영어로, 그 밖의 언어는 한국어로 옮깁니다. macOS 26 이상에서 씁니다.

  • 사전

    낱말을 고르면 macOS 사전의 뜻풀이를 보여 줍니다.

  • 다듬기

    문장을 자연스럽게 다듬습니다. macOS 26 이상에서 씁니다.

  • AI

    친근하게·전문적으로·간결하게 고쳐 쓰거나 표·리스트로 바꿉니다. macOS 26 이상에서 씁니다.

  • 검색

    고른 글로 Google·네이버·DuckDuckGo 중 고른 검색 엔진을 브라우저에서 엽니다.

  • 마크

    웹 페이지의 그 자리를 책갈피처럼 저장합니다.

설치 전 확인할 것

  • macOS 14 이상에서 실행됩니다. 번역·다듬기·AI는 macOS 26 이상이 필요하고, 다듬기·AI는 Apple Intelligence도 켜져 있어야 합니다.
  • 다른 앱에서 고른 글을 접근성 API로 읽기 때문에 손쉬운 사용 권한이 필요합니다. 집게는 권한 요청 창을 띄우지 않으므로 시스템 설정에서 직접 켭니다.

데이터와 개인정보

  • 고른 글을 읽고 다루는 일은 기기 안에서 합니다. 번역·다듬기·AI는 Apple의 온디바이스 모델과 Translation 프레임워크를 씁니다.
  • 예외로 검색·마크·주소 열기는 기본 브라우저를 엽니다. 검색을 누르면 고른 글(최대 200자)이 검색어로 검색 엔진에 전달됩니다.
  • 로그에는 고른 글의 내용을 남기지 않습니다. 대신 선택 시각·앞 앱 이름·글자 수 같은 기록이 기기의 로그 파일에 남습니다.
