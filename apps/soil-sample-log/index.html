토양·퇴비 시료 접수 대장

토양과 가축분뇨 퇴비(퇴·액비 부숙도) 시료의 접수와 관리를 위한 앱입니다. 전국 농업기술센터와 분석기관에서 쓸 수 있습니다.

Windows 다운로드웹에서 바로 쓰기릴리스 노트
설치 전 확인할 것

다운로드 링크는 항상 최신 버전을 가리킵니다. 새 버전이 나와도 한 번 공유한 링크를 그대로 쓸 수 있습니다.

토
주요 기능

토양·퇴비 시료 접수 대장에서 할 수 있는 일

  • 토양 시료 접수·관리

    논, 밭, 과수, 시설로 나눠 토양 시료를 접수하고 관리합니다.

  • 퇴·액비 부숙도

    가축분뇨 퇴비(퇴·액비 부숙도) 시료를 접수하고 관리합니다.

  • 흙토람 검정결과 가져오기

    흙토람 검정결과를 엑셀이나 텍스트 파일에서 가져옵니다.

  • 본필지·하위필지 동기화

    본필지와 하위필지를 자동으로 맞춥니다.

  • 오프라인 우선 저장

    브라우저 저장소(localStorage)와 Firebase Firestore를 함께 쓰는 오프라인 우선 구조입니다.

  • 라벨 인쇄·통계·엑셀 내보내기

    라벨 인쇄, 자동 저장, 통계, 엑셀 내보내기를 지원합니다.

  • 다크 모드

    어두운 화면으로 바꿔 쓸 수 있습니다.

설치 전 확인할 것

  • 설치한 앱은 자동 업데이트를 지원합니다. 한 번 설치하면 이후 새 버전이 자동으로 적용됩니다.
  • 버전별 변경 내역은 릴리스 노트 페이지에서 확인할 수 있습니다.

다른 앱과의 관계

5종 시료를 통합한 시료 접수 대장에서 토양 부분을 분리한 독립 앱입니다. 이후 가축분뇨 퇴비(퇴·액비 부숙도)를 다시 넣어 지금은 2종을 지원합니다. Firebase 동기화를 쓸 때 두 앱의 데이터를 나누려면 각각 별도의 Firebase 프로젝트를 설정해야 합니다.
