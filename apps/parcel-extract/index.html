필지 추출 시스템

농업환경변동조사의 시료 채취 대상 필지를 엑셀 자료에서 추출하는 웹 도구입니다. 이미 채취한 필지는 자동으로 빼고 고릅니다.

필
주요 기능

필지 추출 시스템에서 할 수 있는 일

  • 엑셀 파일 등록

    연도별 채취 필지와 전체 농가 필지를 엑셀 파일(xlsx·xls·csv)로 올려 등록합니다.

  • 컬럼 매핑

    파일의 열을 시스템 항목에 맞추고, 주소에서 리(里)를 자동으로 나눠 냅니다.

  • 중복 필지 자동 제외

    이미 채취한 필지를 자동으로 빼고, 추출할 수 있는 필지 수와 리별 현황을 보여 줍니다.

  • 추출 설정

    리당 추출 수, 농가당 최소·최대 필지 수, 추출 방식을 정합니다.

  • 결과 검토와 조정

    추출 결과를 표로 보며 필지를 직접 넣고 뺍니다.

  • 엑셀로 내려받기

    확정한 결과를 여러 시트로 된 엑셀 파일로 내려받습니다.
