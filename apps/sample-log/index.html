토양·수질·잔류농약·퇴/액비·중금속 5종 시료의 접수, 관리, 조회를 한 앱에서 합니다.

다운로드 링크는 고정 주소라 새 버전이 나와도 바뀌지 않고, 항상 최신 설치 파일로 연결됩니다.

주요 기능

시료 접수 대장에서 할 수 있는 일

  • 5종 시료 접수·관리·조회

    토양·수질·잔류농약·퇴/액비·중금속 시료를 접수하고 관리하고 조회합니다.

  • 엑셀 가져오기·내보내기

    엑셀 자료를 가져오고, 관리하는 자료를 엑셀로 내보냅니다.

  • Firebase 동기화

    Firebase로 자료를 동기화합니다.

  • 라벨 인쇄

    시료에 붙일 라벨을 인쇄합니다.

  • 데스크톱과 웹

    Windows 데스크톱 앱과 설치 없이 쓰는 웹 앱을 함께 제공합니다.

설치 전 확인할 것

  • 설치한 뒤에는 자동 업데이트가 동작합니다. 새 버전이 나오면 앱 실행 중 알림으로 업데이트할 수 있습니다.
  • 설치 없이 브라우저에서 웹 버전을 바로 쓸 수도 있습니다.
